# 环境光平滑与方块云分支

日期：2026-09-15。仅更新独立光照样板，不修改大世界、光传播规则或性能基准。

## 环境光

原天空传播光在方块面上直接读取整数格子，导致洞道出现逐格明暗台阶。本轮将天空光与局部弱补光共用表面切平面的四点插值；拒绝实心样本，对角采样要求两侧空气连通，不跨越墙体法线混合。原来的日月直接遮挡与局部点光源保持原机制。

| 面板参数 | 默认 | 说明 |
|---|---|---|
| 环境光平滑 | 1.0 | 0 为原整格取样，1 为完整平滑；中间值混合两者 |
| 环境光强度 | 1.0 | 0–2，仅缩放天空环境光；不凭空增加最低亮度 |
| 环境光衰减曲线 | 1.4 | 0.5–3；1 保持原线性强度，较大值使深处更暗并柔化到零的过渡 |
| 方块格线强度 | 1.0 | 0–1，独立控制材质上的方格边线，0 便于只观察光照连续性 |

“洞口环境光观察”切到由天井照亮的水平洞道。对照时可关闭日月直射、局部直射及弱补光，单独观察环境光。完全封闭并收敛后仍保持黑暗，不引入环境光保底或完整 GI。传播仍为 0–15 级、六邻域有限距离扩散；插值改善显示连续性，不等同真实多次光线反弹。强度和曲线不改变照明传播距离。

默认会增加天空光显示采样；天空光和弱补光复用同一次四点结果，二者都不需要平滑时跳过额外插值。参数变化不重建网格，不重新传播光照。

## 云分支

新增“云类型”：写实简化体积云 / 方块体积云，默认采用方块体积云。旧配置缺失此字段时使用新默认值；已保存的其他偏好保留。原写实分支仍可选择，其步数和动态变形仅作用于写实分支。

方块云使用 32×32 的周期覆盖图，单格 24 米、周期 768 米，云底 Y=90、厚度 10 米。合并顶部/底部相邻矩形，侧面仅生成外轮廓，不生成内部面；一份网格由 MultiMesh 重复九份覆盖周围天空，没有每格节点。覆盖率改变才重建云网格和遮罩，移动只更新位移。云色与昼夜一致，顶部、底部和侧面有独立明暗差异。

选择方块云或关闭云时，天空材质切到无步进、无半分辨率子通道的简单天空，原写实云计算不运行。原噪声资源保留供分支切换；关闭云后停止位移更新。相机远裁剪提高到 1600 以容纳云几何，地形仍为原有限样板，日月阴影距离仍独立。云几何在远处混合到地平线颜色，不扩大方向光阴影图集。

## 方块云简单阴影

- 默认开启，强度 0.55、边缘柔度 0.3，各自可调；“显示云”与方块云分支是该效果的前提。
- 复用生成网格的二值底部覆盖图，按当前太阳/月亮方向投影。遮光强度统一，不考虑云厚度，不计算云内部自阴影。
- 只乘在方块、草/树叶和水面的日月直射分量上。环境光、发光表面、局部点光源及其阴影不受云影开关影响。
- 柔度为零时单次遮罩采样；开启柔边时四点插值，柔度控制边界过渡宽度。云移位与遮罩偏移同源。
- 日月接近地平线时平滑淡出云影，避免投影偏移无限增大；云底之上的接收面不参与此底面投影。
- 云网格不进入原太阳级联阴影图集。建筑/地形自己的阴影继续生效。

该方案不处理云侧面投影、云层内部、光束或多层云；在低角度光照下侧面遮挡属于近似。覆盖图平铺，远处可能看到重复。它提供较轻的渲染分支，实际性能提升尚未经过正式基准确认；截图 FPS 包含检查过程，不用于帧率承诺。
