# Blender / Godot 角色资产约定

2026-09-23。当前采用 HK416 V8；只维护这一版资产契约。

## 文件与坐标
- Blender 保留可编辑 .blend，Godot 使用明确导出的 .glb。源文件不被游戏侧修改。
- 1 单位 = 1 米。Blender +Z 向上、-Y 朝前；glTF/Godot +Y 向上、+Z 朝前。
- 角色根原点位于双脚之间的地面。源文件各部件可保留自己的编辑原点。
- 绑定前整理旋转与缩放，避免负缩放和非均匀缩放；绑定后不能随意应用变换。
- 固定骨架命名、层级和静置姿态，左右指角色自身。人体骨架名称保留 SkeletonProfileHumanoid 的 PascalCase。
- 导出只含角色、骨架、材质和需要的动画，不含摄影棚、灯光、相机。
- Godot 外层场景负责碰撞、移动、相机和动画控制，不修改导入的 GLB 场景内部文件。

## 骨架与动画
- 推荐规范 T Pose 或 A Pose；同一角色的全部动作共用骨架和静置姿态。
- 每动作独立命名，记录时长、循环、参考移动速度和关键接触时刻。
- 本阶段使用原地动画，Root 不产生位移或旋转；局部骨盆起伏允许。
- 角色全局位移、跳跃高度和落地由 CharacterBody3D 决定，动画仅表现。
- 外部动作重定向需另行验证，BoneMap 不代表已完成兼容。
- IK、手指、表情、头发布料物理暂不要求。
