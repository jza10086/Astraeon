# P1 / P2 模块化光影

日期：2026-09-14；2026-09-15 增加[环境光平滑与方块云分支](lighting_environment_clouds_20260915.md)，该文档为最新增量说明。水面、局部光源、简化体积云及阴影/FPS 控件已按确认方案更新，详见 [本轮实现与限制](lighting_update_20260914.md)。状态：功能已接入独立光照样板，完成设置/资源检查和短时 D3D12 实际渲染检查。主游戏、大世界流式光照与原性能基准未改动，没有运行性能基准或优化专项。

## 使用

~~~powershell
./tools/lighting_sample.ps1 -Run
~~~

点击创建光照样板。左侧面板可滚动：上部是时间和观察点/编辑按钮，下部是按模块分组的开关和参数。“恢复默认设置”只恢复光影设置，不重置体素编辑。右键环视、WASD 移动、Q/E 升降。

当前完整功能位于嵌套工程的 astraeon_lighting/。P0 数据模型和有限场景边界继续适用，详见 [P0 文档](lighting_p0.md)。

## P1

| 模块 | 默认值 | 行为 |
|---|---|---|
| AO | 开，强度 0.65 | 材质在白色与现有顶点 AO 之间插值；关闭不重建网格、不改光传播 |
| 距离雾 | 开，起始 24，浓度 0.006 | Godot 非体积深度雾，终点 = 起始 + 1/浓度；颜色跟随同一天空参数 |
| 抗锯齿 | FXAA | 关闭/FXAA/TAA 互斥，使用引擎实现 |
| 阴影 | 开，距离 96，中档 | 硬/软阴影可切换，独立调节模糊半径；日月阴影贴图 1024/2048/4096/8192，默认 4096；不改变地形视距 |
| 阴影调试 | bias 0.06、normal bias 1.7 | 暴露偏移参数，开启级联混合 |
| 曝光 | 固定 1.0 | 保留 Filmic，不引入自动曝光 |

添加阶梯、墙角窄缝、远近遮挡柱。模块显示变化不使光照数据或几何失效。TAA 使用引擎历史管理，没有新增 Compositor 或自定义历史修复。

## P2

- **水面**：X [12,28)、Z [-25,-9)，静态水位 Y=0.75。浅区底部 Y=-2，深区底部 Y=-5。两个网格使用连续世界坐标波相位；默认波纹开启、强度 0.12。
- **吸收与反射**：默认单次场景深度采样估算视线水体厚度，低画质回退统一水色，Fresnel 混合当前天空色彩。属于近似天空反射，不反射云层或场景物体；无 SSR、屏幕空间折射或液体模拟。
- **水下**：按相机是否位于固定水体内切换蓝绿色深度雾，距离 12；出水恢复空气雾设置。使用静态水位判断，不随波峰逐帧跳变。“显示水面”只控制表面，水下效果有独立开关。
- **植被**：草使用两个交叉裁剪面，以 MultiMesh 显示；树叶使用独立裁剪材质，树干保持原材质。风动强度默认 0.12，根部固定，阴影执行同一顶点变形。裁剪轮廓为程序化占位图案。
- **透光**：背光照明项独立控制，默认强度 0.25；没有修改基础体素传播，树叶体素仍不透光。视觉孔洞与体素光照阻挡的差异是已知近似。
- **云**：MakeUp 式单层高度场简化体积云，半分辨率、默认 24 步、覆盖率 0.45、速度 0.015，动态形变默认关闭；颜色随昼夜变化，关闭后停止独占时钟更新，不投射地面阴影。
- **Bloom**：Godot Glow，默认关、强度 0.6。关闭后发光方块及其周围基础光照仍保留。

独立水池、草地与新增观察点用于分别观察水上、水下、逆光植被和夜间光源。波纹较轻；当前水色跟随场景深度，阶梯池底仍会产生真实的厚度变化，原两半网格固定水色接缝已移除。

## 配置与接口

AstraeonLightingProfile 按模块导出字段；运行时复制模板。新增 load_settings/save_settings 方法，保存已知导出字段到嵌套工程 user://settings.cfg 的 lighting 节；可读取旧 lighting_p0 节作为缺省回退。数值检查类型、有限值和范围；缺失设置保留默认，其他配置节保留。恢复默认后仍保存同一路径。

样板 settings_path 默认为上述路径，自动检查覆盖为专用测试文件。自动测试不会覆盖用户真实偏好。设置面板只绑定本地资源；environment_details.gd 管理有限水池和草；没有新增 autoload。

关闭风动、云和水波后停止对应时钟更新。关闭 AO 改为白色 AO 权重；关闭水面天空反射保留基础水材质；关闭水下效果使用空气环境；各模块不暗中开启其他开关。

## 已确认决定（已于本轮统一执行）

- 水面：默认采用单次场景深度采样，估算逐像素水体厚度并计算吸收和透明度；低画质档回退统一水色。不加入折射或 SSR。
- 已接入材质和画质配置；处理无效深度与有限水池视线出界，透明物体深度仍是近似，详见本轮文档。

### 局部光源：自然直射与平滑补光

状态：已接入带阴影点光源和可独立关闭的弱补光。定向灯具尚无样板实体，聚光灯作为未来灯具路线保留。

- 目标：方块几何保持体素风格，光照连续变化，没有按格跳变的明暗；局部遮挡、衰减和阴影像当前太阳光一样自然。
- 发光表面：保留材质自发光，Bloom 独立可选；表面发亮与照亮周围分开。
- 局部直射：使用带阴影的点光源；定向灯具使用聚光灯。先保证墙体和孔口遮挡正确，再调节衰减和阴影柔度。首版以有效发光点近似发光方块，不实现面积光。
- 间接补光：将现有方块传播光降为较弱的补光，增加考虑遮挡的平滑采样；不能只用普通线性过滤掩盖硬边，也不能让绕孔传播形成大范围强光。
- 开发顺序：先关闭方块传播的显示贡献，单独验证局部直射与阴影；正确后逐步加入弱补光。此处关闭的是显示贡献，不删除世界光照数据。
- 验收场景：光源紧贴墙壁，依次单格开孔、完全封闭；开孔时只应在直射可达区域形成主要亮区，孔旁背向光源的外墙不出现大范围强光，封闭并完成更新后外部保持黑暗；墙面明暗连续，阴影适度柔化。
- 范围：功能优先，暂不引入完整动态 GI、面积光近似或大量光源性能优化。水面方案同步执行。

### 云：MakeUp 式简化体积云

状态：已用单层高度场简化体积云替换原二维云。

- 目标：从地面观察具有柔软轮廓、厚度和自然明暗的写实云层，不以云内部或穿云体验为目标。
- 路线：参考已下载 MakeUp 9.5e 的简化体积算法，使用二维纹理控制云层上下边界，沿视线少量步进累积不透明度，以近似明暗代替复杂三维密度、光照二次步进和完整物理散射。
- 初步实现方向：单层高度场体积云、半分辨率渲染；先保持云形状并整体移动，动态形变作为独立可选项。采样数量与质量档位留待实现和实测确定，不承诺具体帧率。
- 范围：本次确认仅涉及云本身的渲染，不包含地面云影或云层遮罩投影；此前讨论的仅响应日月光、统一遮光强度方案尚不视为本次实施范围。
- 保持云模块独立开关并复用昼夜参数；实际渲染与配置检查已进行，性能基准待后续安排。实现为项目自编算法，未复制第三方源码或纹理。

### 已执行：日月阴影默认偏移

用户在低太阳高度角下确认法线偏移 1.6 以上基本消除地面条纹，暂未发现副作用。按用户指定将默认 shadow_bias 设为 0.06、shadow_normal_bias 设为 1.7；软阴影过滤模式保持原设置。已有 user://settings.cfg 中保存的偏好仍优先，重新启动后恢复默认可应用新值（会恢复全部光影设置）；当前运行实例不自动热更新。其他视角、细小阴影及接触阴影仍需后续视觉验收。
