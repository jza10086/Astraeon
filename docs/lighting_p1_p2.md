# P1 / P2 模块化光影

日期：2026-09-14。状态：功能已接入独立光照样板，完成设置/资源检查和短时 D3D12 实际渲染检查。主游戏、大世界流式光照与原性能基准未改动，没有运行性能基准或优化专项。

## 使用

~~~powershell
./tools/lighting_sample.ps1 -Run
~~~

点击创建光照样板。左侧面板可滚动：上部是时间和观察点/编辑按钮，下部是按模块分组的开关和参数。“恢复默认设置”只恢复光影设置，不重置体素编辑。右键环视、WASD 移动、Q/E 升降。

当前完整功能位于嵌套工程的 astraeon_lighting/。P0 数据模型和有限场景边界继续适用，详见 [P0 文档](lighting_p0.md)。

## P1

| 模块 | 默认值 | 行为 |
|---|---|---|
| AO | 开，强度 0.65 | 材质在白色与现有顶点 AO 之间插值；关闭不重建网格、不改光传播 |
| 距离雾 | 开，起始 24，浓度 0.006 | Godot 非体积深度雾，终点 = 起始 + 1/浓度；颜色跟随同一天空参数 |
| 抗锯齿 | FXAA | 关闭/FXAA/TAA 互斥，使用引擎实现 |
| 阴影 | 开，距离 96，中档 | 质量控制方向光软阴影过滤；不改变地形视距或阴影贴图尺寸 |
| 阴影调试 | bias 0.08、normal bias 1 | 暴露偏移参数，开启级联混合 |
| 曝光 | 固定 1.0 | 保留 Filmic，不引入自动曝光 |

添加阶梯、墙角窄缝、远近遮挡柱。模块显示变化不使光照数据或几何失效。TAA 使用引擎历史管理，没有新增 Compositor 或自定义历史修复。

## P2

- **水面**：X [12,28)、Z [-25,-9)，静态水位 Y=0.75。浅区底部 Y=-2，深区底部 Y=-5。两个网格使用连续世界坐标波相位；默认波纹开启、强度 0.12。
- **吸收与反射**：按已知深度调整水色和透明度，Fresnel 混合当前天空色彩。属于近似天空反射，不反射云层或场景物体；无 SSR、屏幕空间折射或液体模拟。
- **水下**：按相机是否位于固定水体内切换蓝绿色深度雾，距离 12；出水恢复空气雾设置。使用静态水位判断，不随波峰逐帧跳变。“显示水面”只控制表面，水下效果有独立开关。
- **植被**：草使用两个交叉裁剪面，以 MultiMesh 显示；树叶使用独立裁剪材质，树干保持原材质。风动强度默认 0.12，根部固定，阴影执行同一顶点变形。裁剪轮廓为程序化占位图案。
- **透光**：背光照明项独立控制，默认强度 0.25；没有修改基础体素传播，树叶体素仍不透光。视觉孔洞与体素光照阻挡的差异是已知近似。
- **云**：单层程序化二维云，默认覆盖率 0.45、速度 0.015；颜色随昼夜变化，关闭后停止独占时钟更新，不投射地面阴影。
- **Bloom**：Godot Glow，默认关、强度 0.6。关闭后发光方块及其周围基础光照仍保留。

独立水池、草地与新增观察点用于分别观察水上、水下、逆光植被和夜间光源。首版波纹较轻；深浅水区是阶梯池底，因此颜色有明确分界，不代表连续地形深度查询。

## 配置与接口

AstraeonLightingProfile 按模块导出字段；运行时复制模板。新增 load_settings/save_settings 方法，保存已知导出字段到嵌套工程 user://settings.cfg 的 lighting 节；可读取旧 lighting_p0 节作为缺省回退。数值检查类型、有限值和范围；缺失设置保留默认，其他配置节保留。恢复默认后仍保存同一路径。

样板 settings_path 默认为上述路径，自动检查覆盖为专用测试文件。自动测试不会覆盖用户真实偏好。设置面板只绑定本地资源；environment_details.gd 管理有限水池和草；没有新增 autoload。

关闭风动、云和水波后停止对应时钟更新。关闭 AO 改为白色 AO 权重；关闭水面天空反射保留基础水材质；关闭水下效果使用空气环境；各模块不暗中开启其他开关。
