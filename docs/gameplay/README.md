# 交互与玩法

## 职责与当前进度

已实现玩家物品栏、10 槽快捷栏、独立鼠标持物及创造分类选取、物品操作事务、挖掘/放置与背包数量联动；世界场景负责装配。

## 架构与数据流

静态物品定义 → InventoryState → UI 操作请求；InventoryInteraction 校验目标与物品数量，经 InventoryStore 日志提交后调用世界编辑接口。

## 详细文档与入口

[物品栏与交互](inventory.md)、[世界接口](../world/native_voxel_backend.md)。

源码与测试入口：game/gameplay/interaction、inventory、crafting、survival。

## 限制与待办

地面掉落、部分拾取与配对保存已接入；满背包仍能挖掘。尚无箱子实体、配方、工具耐久或完整生存压力；玩家位置仍未保存。

## 验证证据

[测试入口](../../test/README.md)；历史通过记录不代表本次重跑。整体状态见 [整体概览](../../total_development.md)。研究资料见 [tmp](tmp/README.md)。

编译包内物品接入创造目录与放置/挖掘事务。放置需视觉就绪后才修改数量/世界；背包/玩家/掉落物格式4绑定世界注册表标识，允许追加Mod状态。

## 模式与玩家状态

生存／创造切换、共享背包、创造飞行及初始 10/10 的生命／饱食度已实现，状态纳入库存双快照。规则、API 和边界见 [模式与状态](modes.md)。

## 长按挖掘与阶段裂纹

主世界生存模式每 0.05 秒结算挖掘，空手为 1 耐久度/秒，匹配单一方块工具标签时采用工具速度。各坐标分别保留损伤，默认停止 30 秒后恢复，可逐方块配置；创造即时破坏不变。当前准星目标显示十阶段保留裂纹。

字段、初版数值、状态边界与测试见 [方块挖掘](mining.md)。
