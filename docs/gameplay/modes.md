# 生存、创造与玩家状态

## 当前规则

创建世界默认生存，可选择创造；暂停菜单可以切换，保存成功后生效且保持暂停。两种模式共享 40 格背包、选中槽和鼠标持物，切换不恢复数值、不清空物品，创造领取的物品可带回生存。

生存仅显示储物区和快捷栏，按住左键持续挖掘，完成后产生地面掉落物，放置消耗一个。创造显示分类、搜索和储物页，允许目录取物、复制、删除和清空；放置不消耗，点击即时破坏非空气、非流体方块且不产生掉落。两种模式均保留编辑范围、加载状态、玩家碰撞、目标占用及外观就绪校验。免费编辑也写入地形恢复日志。工具加速及损伤保留规则见 [方块挖掘](mining.md)。

## 状态接口与边界

`game/gameplay/survival/gdscript/player_state.gd` 定义场景局部 `AstraeonPlayerState`；初始生命、饱食度及各自上限为整数 10，范围 0—10。`increase_health`、`decrease_health`、`increase_hunger`、`decrease_hunger` 接受非负整数并钳制结果，返回提交是否成功。负参数和不可操作状态返回 false；候选值保存成功后才发出 changed。

底层接口与模式无关，创造也可显式扣除。未来跌落、溺水或其他伤害规则负责判断是否调用。没有食物、自动消耗、饥饿扣血、回血、死亡或重生规则；0/10 仅为数值。玩家位置仍未保存，现有越界回位不属于死亡系统。

## 界面与飞行

两种模式的快捷栏上方均显示生命和饱食度矩形条（各 310×26，间隔 16），红色生命、橙色饱食度，居中显示当前值/上限。背包打开时隐藏，暂停时保留在遮罩后。

创造双击空格（0.3 秒）切换飞行，WASD 水平移动、空格上升、Ctrl 下降、Shift 加速。速度 8/16 m/s，合成方向归一化；保留碰撞、无输入悬停。切回生存关闭飞行并清空运动缓存，恢复重力。菜单清空输入和双击计时；飞行开关不保存。详见 [输入映射](../input_mapping.md)。

## 保存与职责

世界参数格式 2 保存 initial_mode。库存双快照格式 4 保存当前玩家模式、生命、饱食度、槽位、鼠标持物、掉落物和未完成地形日志；当前模式以快照为准。拒绝旧格式，无迁移。失败不发布候选状态；运行 I/O 失败停止受影响世界。

玩法维护状态及权限；entities 执行飞行运动；UI 仅显示和提交请求；world 保持唯一体素权威并组装状态。没有新增全局服务。
