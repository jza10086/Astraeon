# 物品栏、快捷栏与方块交互

## 当前闭环

玩家拥有 40 格：前 10 格为快捷栏，后 30 格为储物区。快捷栏与背包底行引用相同槽位，不复制物品。真实世界首次进入为空背包，通过挖掘取得物品；独立样板预填物品，不写入正式存档。当前支持草、泥土、树叶、木头和发光石；水不是可堆叠物品。支持直接移除手上物品，暂无装备、工具耐久、合成、箱子实体或地面掉落物。

## 静态与动态边界

- game/data/item：ItemDefinition/ItemCatalog 共享 Resource，定义稳定 key、名称、图标或占位色、堆叠上限、目标方块和朝向规则。五种物品采用 astraeon_xxx_item，默认最多 64。
- game/data/inventory：玩家容器定义，10 个快捷槽、3 行储物区。
- gameplay/inventory：ItemStack 是 RefCounted 数量状态；InventoryState 持有 40 个槽位、独立临时鼠标堆叠、选中索引、revision 与锁状态。stack_at/cursor_stack 返回副本；空槽/空手为 null，不保留零数量对象。鼠标堆叠既不占第 41 个存储槽，也不预留来源槽位。
- world 仍是唯一权威体素源；背包不保存体素镜像或世界朝向。三轴原木进入背包统一堆叠，放置时根据命中面的法线选择 axis_x/y/z。
- UI 只发送操作请求，不直接改数量。图标目前为简单颜色立方体，可通过静态 icon 资源替换。

## 操作与事务

InventoryState 提供 insert、consume、指定版本的 move、quick_move、select；鼠标操作使用 click_slot、creative_pick、clone_to_cursor、discard_cursor 和 clear_inventory。槽位变化与鼠标变化由 _commit_with_cursor 一起发布：先生成候选值，再调用持久化守卫，成功才发 changed；失败时槽位和鼠标都不变。鼠标复制、目录取物和删除仅修改瞬态数据，不写盘。当前只有玩家单容器及其两个分区，不实现跨箱子事务。

InventoryInteraction 接收世界坐标和放置面，检查区段可编辑、世界边界、目标占用、玩家碰撞及可用物品。挖掘按方块类型掉落一个对应物品，先检查容量；满栏拒绝挖掘，水和未定义掉落的状态不删除。放置仅替换空气/水，扣除选中槽位一个物品。操作成功才调用已有 world.set_block，使原生网格和光照失效机制继续生效。没有挖掘时长或工具规则。

## UI 与输入

1920×1080 基线，60×60 正方形槽位、4 像素间隙；底部快捷栏宽 636、底边距 18，选中格浅色粗描边，数量右下角，键位左上角。背包居中，面板内 3×10 储物区与独立间距的 1×10 快捷栏；简单灰色面板与背景遮罩。使用 anchors/containers，沿用项目 canvas_items/expand/fractional。

- E 打开/关闭；Esc 关闭。打开时释放鼠标、清空移动意图并禁用玩家输入；关闭恢复。
- 1—9 对应前九格，0 对应第十格。滚轮向上前一格、向下后一格，首尾循环。背包打开时滚轮不切换；F6 设置打开时数字键/滚轮/E 不操作背包。
- 储物槽左键立即拿起整堆并清空来源，右键拿起上取整的一半；手上有物品时左键放入/合并，右键放一个。异类目标与手上整堆交换，满的同类槽不改变数量；中键复制目标类型的满堆到鼠标。
- Shift+左键在快捷栏与储物区间快速转移，保留手上物品。采用点击拿起、再次点击放下，不依赖 Godot 拖拽占位或来源 revision 预览。
- 鼠标图标与数量跟随指针，忽略鼠标命中；切分类/搜索/储物页均保留持物。背包塞满时仍可从目录拿一组到鼠标，不自动挤入格子。
- 点击面板外或移除格：左键删除手上整堆、右键删除一个；储物页 Shift+左键移除格清空 40 格及手上物品，仍须通过保存守卫。关闭背包直接删除手上整堆，不返还、不生成地面实体。
- 悬停显示名称、数量与物品 ID。没有装备/合成占位按钮。
- 背包与 F6 光影设置互斥。重新捕获鼠标的左键由玩家控制器消费，不同时挖掘。

完整按键条件见 [输入映射](../input_mapping.md)。

## 保存与恢复

InventoryStore 在世界目录写 inventory_a.json / inventory_b.json 两份交替快照，包含格式版本 1、序号、SHA-256 校验、种子/生成版本/布局/状态表签名、稳定物品 key/数量/选中槽位，以及尚未确认地形落盘的坐标→最终状态 key 日志。

每次槽位/选择变化先完整写入并 flush 候选快照；挖掘/放置的物品变化与坐标修改记录在同一个快照内，然后才发布内存物品变化并编辑体素。重启在启动地形工作线程前检查快照，将未完成修改按 section 分组，经已有 C++ 区域读写接口恢复；重复恢复是幂等的。只有原生保存完成且流式写队列空闲时才移除日志，否则保留供下次恢复。保存期间锁定取物和放入操作，但允许删除已离开槽位的鼠标临时物品。

只接受当前格式、注册物品及世界标识；非法数量、未知物品、世界不匹配报错并阻止进入。中断写入可使用另一份校验通过的日志。FileAccess.flush 不代表硬件断电保证；任意磁盘损坏、双文件同时损坏、多进程同时写世界不在保障范围。只保存背包与选中槽位，玩家位置、生命值仍未保存。鼠标堆叠不持久化：从槽位拿起时已把扣除后的槽位写盘，所以关闭或退出、重启后不会返还手上物品；这与本阶段的直接移除规则一致。存档槽位格式仍为当前格式 1，没有新增旧格式读取路径。

## 创造选取与分类

E 打开同一创造背包：主分组标签在上方，搜索标签固定右上，储物栏标签固定右下；全部页面共用底部 10 格快捷栏。分类溢出时顶部水平滚动，目录网格为 10 列并垂直滚动，储物页为 3×10 槽；使用相同 60×60 立方体图标，不再使用名称大按钮。搜索页空查询列出全部 5 种可放置方块。

目录左键取一个到鼠标；相同类型连续点击逐个增加至上限，中键取满一组。选择其他类型会替换手上的临时堆叠；目录右键移除手上一个。目录取物不受背包容量限制、不直接写入背包；点击实际槽位才提交存储事务。储物页左下移除格处理直接删除，分类和搜索页可点击面板外删除。

这是原型的创造选块工具，对当前玩家开放；尚未引入生存／创造模式权限切换、飞行、无敌或无限放置。放置仍消耗数量。水为流体定义，不在方块物品目录中；原木的三轴朝向只显示一个木头条目。

静态分类由 `AstraeonItemCatalog.creative_groups: Dictionary[StringName, String]` 定义有序 ID → 显示名；`AstraeonItemDefinition.creative_group: StringName` 引用唯一主分组，`search_tags: PackedStringArray` 保存多个 sub tag（搜索关键词）。这些是领取物品的展示分类，存放 game/data/item，引用既有 block 定义；不在 BlockDefinition 和 ItemDefinition 双份维护。新增分组修改目录映射，新增方块设置组与标签即可，不增加 UI 分支。

主组 ID 使用 astraeon_ 前缀且稳定，显示名可以修改。标签当前允许中文别名、英文关键词；只影响搜索，不用于碰撞、燃烧、配方等玩法判定。验证拒绝未知分组、空标签和大小写重复标签。主组单选，标签多选；「全部」是查询视图而非存档分类。若未来配方需要语义标签，另定义受校验的 gameplay 标签，不能复用自由搜索文字。

搜索对名称、物品 ID、方块 ID、分组显示名和标签做不区分大小写的包含匹配；空格分隔的词须全部命中，搜索页查询所有分组；分类页只按分组列出内容，不继承搜索词。小目录按输入变化扫描；没有逐帧扫描，也不把分类写入每个 ItemStack 或体素。仅背包数量/选择槽持久化；查询词、当前分页属于临时 UI 状态。

搜索框拥有焦点时 E 和数字输入文字，Esc 关闭；失去搜索焦点后仍用 E 关闭、1—0 选槽。滚轮在面板内滚动结果，不切快捷槽。
