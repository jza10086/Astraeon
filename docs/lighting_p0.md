# P0 光照样板

状态：2026-09-14 已实现独立样板与自动正确性验证；已完成实际 D3D12 渲染和脚本驱动交互检查；完整键鼠人工验收与性能测试尚未进行。主游戏仍是占位场景。

## 启动

在项目根目录执行：

~~~powershell
./tools/lighting_sample.ps1 -Run
~~~

窗口打开后点击“创建光照样板”才创建体素数据和网格。也可以用 Godot 4.7 打开 `benchmarks/voxelgame/project`，对 `astraeon_lighting/lighting_sample.tscn` 按 F6。F5 仍是原性能基准的准备页面。

使用左侧按钮切换正午、日落、夜间，或独立控制时间推进、天空渐变、直射光、实时阴影。四个观察点覆盖室外、窗边、屋内和地下。按住右键环视，WASD 移动，Q/E 升降，Esc 释放鼠标。准星按钮可挖掘、放置普通方块或发光方块；固定按钮可开闭屋顶和窗口、切换室内光源，以及一次切换 128 方块。

首版使用飞行观察相机，没有角色碰撞或生存玩法。测试操作只改变内存中的样板。时间与四个开关保存到嵌套工程自己的 `user://settings.cfg` 的 `lighting_p0` 节；不修改主游戏设置或玩家存档。色彩、曝光、阴影距离及传播预算可在 `astraeon_lighting/default_profile.tres` 配置；运行时复制资源，不修改共享模板。

## 边界与模块

- 有限范围 X/Z [-32, 32)、Y [-16, 48)，共 64³ 体素。chunk 仍定义为水平 16×16 列，section 为 16³。
- 样板使用 Voxel Tools 原生 block mesher 为每个 section 生成一个网格，复用其面剔除和顶点 AO。不创建逐方块 Node，也不增加新的原生补丁。
- 这是有限光照样板，没有接入 VoxelTerrain 的流式生命周期。原 256 半径圆形加载、独立垂直范围、512 总高度以及测试脚本均未改动；本样板不能验证该规模性能。
- 光照数据由 `light_volume.gd` 管理；有限场景构造与编辑夹具由 `sample_world.gd` 管理；`section_meshes.gd` 管理派生几何；控制脚本组装相机、UI、天空、材质和灯光。
- 空气、完全不透光方块和不透光发光方块是当前遮挡模型。树冠为不透光占位方块，未实现树叶半透明、玻璃、水或彩色透射。

## 光照契约

体素 ID 是权威数据；天空光和方块光分别用一个 byte 存储 0–15 强度，不写最终颜色。

天空光：从有限体积的最高层向下扫描；空气直通上边界时获得 15，遇不透明体素停止。其他空气沿六邻域取最大邻居值减一。只有上边界提供天空光，侧边、底边以及未知区域不注入光。这个有限顶部假设不适用于任意高度的流式加载窗口，未来接入时必须查询完整遮挡列。

方块光：发光方块自身值为 15，向空气传播，每个六邻域边衰减一。多个来源取最大值。方块材质的自发光与照亮周围的传播是不同数据用途。

`apply_edits(Dictionary[Vector3i, int])` 合并事务并返回实际改变的体素位置；越界编辑忽略，非法 ID 拒绝，无变化不增加版本。受影响 XZ 列去重重扫，邻域加入去重队列。预算化松弛同时处理旧光消退与新光传播；所有非源传播边都有衰减，移除光源后旧循环无法自持。不是每次编辑都全量重算。

`step(max_cells, budget_usec)` 在主线程推进，不修改后台场景树。预算为软预算，单列扫描不可拆分。连续编辑使用最新体素数据继续收敛；只有队列清空且版本匹配才发布光照纹理。编辑时几何可先更新，上一份光照纹理会暂时保留到收敛，尚无几何与光照的同步交换保证。

`make_images()` 是显示适配边界：将天空/方块光映射到 RG8，0–15 对应 0–255。首版完整上传 64 个切片，共 512 KiB；每次收敛后最多提交一次。打包与上传提交当前仍是整块同步操作，不受传播预算约束。后续规模化必须处理分页、局部上传和加载边界，不能把这个完整 3D 纹理直接扩大到生产视距。

几何只因体素 ID 变化重建；包含边角 AO 的一体素邻域会使相邻 section 失效。每帧最多构建一个 section，原生 mesher 调用仍为原子操作，没有硬耗时保证。光照变化和时间变化不会导致网格重建。

## 材质、天空和阴影

方块材质在表面外侧相邻空气体素采样光照，最近邻采样避免三线性插值穿墙；代价是首版可见离散光级。现有顶点 COLOR 保留 AO 用途，基础材质颜色独立传入。纹理体积外的采样为黑，有限世界外侧面可能较暗。

关闭全局环境补光及天空反射，使用天空光强度乘天空光颜色作为局部环境照明，使用方块光强度曲线乘统一暖色作为方块照明。两者作为材质附加照明输入，不是动态 GI 或多次反射。直射采用 Godot 内置 DirectionalLight3D 与级联阴影，并以天空可达性抑制密闭室内直射。阴影关闭时仍有基础明暗，接受树影和直射遮挡精度下降。

太阳/月亮共用一个方向光，按时间切换方向和能量；天空、环境色、直射色共用同一个时钟。时间推进关闭时停止时钟更新。天空渐变可以独立关闭，保留基础天空颜色。默认阴影距离 96 体素，独立于地形视距；关闭直射或阴影会关闭对应阴影绘制。

默认使用固定曝光 1.0 和 Godot Filmic 色调映射。无自动曝光、Bloom、SSAO、体积雾、光束、水面、云或 GI。没有新 Compositor pass。

首版统一暖色方块光，参考 MakeUp 的“光强曲线 × 统一光源颜色”结构，代码重新实现，未复制其 GLSL。未来多个独立颜色的光源需要 RGB 传播与混合算法；仅改变当前统一颜色不能实现彩色混光。显示适配边界支持未来替换数据布局，但当前没有预分配 RGB 光照。
