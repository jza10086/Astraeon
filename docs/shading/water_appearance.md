# 水体外观运行时接口

制作字段见 [资源规格](../resource_specifications.md#水体外观规格)。

## 当前接口与接入边界

surface_parameters() 返回新的 uniform 参数字典，调用方在创建或切换共享水材质时应用；禁止逐水体素创建 Material。wave_speed 由调用方用于更新 clock，水下参数由环境控制器读取。scene_reflection_parameters(planar) 仅返回所选反射分支的强度参数；无场景反射时不调用。接口不会开启任何效果，也不修改资源。

全局光影配置负责水开关、统一水色/深度吸收选择、波纹/天空反射/水下开关、SSR/平面反射选择，以及步数、分辨率、更新频率等质量预算。接入后外观值来自本资源，配置只负责策略，避免同一字段被两处反复覆盖。当前独立样板尚未改接，仍沿用原有 profile。正式地图通过 BlockLibraryBuilder 接入固定厚度统一水色、透明度、粗糙度和高光；主世界和样板的波纹、反射、水下效果由全局 profile 驱动；这不表示这些字段已经按流体类型从本资源读取。

水位、体积边界、流动状态和相机是否在水下由世界及场景提供；天空颜色来自现有昼夜系统；反射纹理和矩阵由反射组件提供。资源不包含这些实例状态，也不包含逻辑碰撞/透光规则。

历史测试池边界描述不作为当前世界限制。当前原生水网格、公共水位及反射限制见 [主世界光影](world_shading.md)，新增水面与水下效果见 [水面与光束](water_light_shafts.md)。

## 验证

Godot 4.7：`--headless --path . --script res://test/shading/gdscript/test_water_appearance.gd`，历史验证 49 项检查通过，覆盖无效值、共享资源隔离、参数映射和保存重载。上述资源检查不包含后续水体渲染和性能验收；当前接入状态见前述边界。

2026-09-26：水下旧距离字段已替换为衰减率和起始距离，当前控制与限制见 [水面与光束](water_light_shafts.md)。主世界与样板共用 distance_fog.gd，但仍以全局 profile 控制水下外观；按流体类型读取此资源的水下参数仍待接入。
