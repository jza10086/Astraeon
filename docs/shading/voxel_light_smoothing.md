# 体素传播光与显示平滑

## 职责与数据

正式世界由 C++ SectionLightCache 维护每格 0–15 天空光、方块光与阻光值。六邻接传播扣 max(1, opacity)，直射天空柱扣 opacity；多光源取可达贡献最大值，不将所有灯相加。光场按 16³ section 缓存并发布 GPU 页。样板是采用同一规则的有限参考求解器。

显示平滑不改变光源半径、传播拓扑、保存内容或编辑规则，不触发网格重建。表面自发光、点光源、AO 和最低环境光仍是独立效果。

## 参数与默认值

正式世界 F6 与 shading_sample 使用相同面板和 runtime_data/settings.cfg 的 shading 节。

| 位置 | 参数 | 默认 | 含义 |
| --- | --- | --- | --- |
| 光照 → 环境光与 AO | 传播光平滑方案 | 九点柔和 | 关闭逐格、四点线性、九点柔和互斥 |
| 光照 → 环境光与 AO | 环境光平滑 | 1.0 | 对天空环境光及日月直射天空可见度共同生效；0 恢复逐格采样 |
| 光照 → 局部照明 | 方块光平滑强度 | 1.0 | 对体素主照明和弱间接补光生效 |
| 光照 → 局部照明 | 方块光亮度曲线方案 | 幂函数 | 可切换 MakeUp 风格，保留峰值归一 |
| 光照 → 局部照明 | 方块光衰减曲线 | 1.6 | 幂函数指数，仅幂函数方案显示 |
| 光照 → 环境光与 AO | 环境光衰减曲线 | 1.4 | 天空环境亮度曲线；不改日月遮挡与逻辑传播 |

无传播照明时隐藏方块光的相关设置，关闭采样平滑时隐藏两个平滑强度。选择 MakeUp 曲线不会暗中提高光强。默认局部照明方案未改变；要单独观察传播光，选择“体素传播光”。

## 显示算法

四点线性在体素表面外侧的切平面上读取格心光值。它连续但在格心容易出现梯度折线。九点柔和采用 3×3 正权重二次 B 样条核，开放区域在格心及格边保持一阶连续，没有负权重和过冲。每个方向只扩展一格，保留已有 GPU 页邻接范围。

所有方案均不沿表面法线穿墙采样。完全阻光或未知单元不参与加权；斜角采样要求两条正交邻格均通透，剔除样本后重新归一。遮挡拓扑改变的地方不承诺数学连续，因为防穿墙优先于视觉模糊。树叶 opacity 1 可以参与插值。

原实现日月直射 sky_visibility 单独取格值，未跟随环境平滑。现在两个体素材质（实体和植被）均使用混合后的天空可见度，消除这一条独立的阶梯来源。

MakeUp 风格响应：令 x 为平滑后的 0–1 方块光，采用 (x^1.5 + 1.17^6 * x^6)/(1+1.17^6)。依据上游 light_vertex 的形状独立实现并归一峰值，保留项目颜色、能量和曝光控制。它不是 MakeUp 的逐像素等价复刻：上游在顶点阶段处理光色，整体光照映射、色调映射和颜色空间也不同。默认仍用较均匀的幂函数，便于与原效果对比。

## 边界与成本

- 六邻接的曼哈顿距离和多源 max 合并仍可能形成菱形轮廓/交汇线，滤波只是软化过渡，不会变成物理点光或全局光追。
- 九点模式从最多 4 个光场样本增加到 9 个，跨 section 时还需页表查询。关闭对应贡献后尽量跳过滤波；不因此增加 CPU 求解或发布频率。成本必须另行实测，不能把截图 FPS 当基准。
- AO、方块描边、低分辨率阴影和最终输出量化仍可能造成“分块感”。滤波不负责抹平这些独立因素。
