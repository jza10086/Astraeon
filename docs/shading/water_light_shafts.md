# 水面与 MakeUp 式光束（2026-09-25）

主世界与 test/shading 样板共用 game/shading 中的实现。计算运行在 GPU；GDScript 负责相机、资源、设置与参数提交，没有逐体素 GDScript 光照计算。

## 水面

- 天空与水面共用 sky_appearance.gdshaderinc：方向渐变、日月形状、贴图、颜色与光晕。
- 天空回退可查询现有方块云底部分布；这是薄层近似，不包含云侧面。
- 三个不同尺度、方向的噪声法线层，与几何起伏独立。细节随距离减弱。
- 保留单次深度厚度吸收；可选折射额外采样背景颜色与偏移位置深度，拒绝前景和岸边。
- SSR / 平面反射互斥；未命中时混合方向天空。日月没有另加重复高光倒影。
- 默认：SSR，折射开启，正视反射率 0.02，几何波高 0.025m，大波纹法线 0.22，细波纹 0.1，细节衰减距离 100m。
- 天空可见度目前为显式参数，洞穴水的逐点方向天空遮挡尚未实现。
- 平面反射仍是一张水平水面；折射仍只能读取屏幕内已绘制背景。两者不是液体模拟。
- 未开启折射时不执行偏移深度查询；由于材质声明了屏幕纹理，引擎仍可能准备屏幕副本，不能声称零额外成本。

## 光束方案

| 选项 | 算法 | 专属工作 |
|---|---|---|
| 关闭 | 不合成光束 | 停止捕捉与光束 dispatch |
| MakeUp 深度光束 | 朝日月屏幕位置采样天空可见性，按朝向/昼夜/天气合成 | 默认4步、半宽半高 |
| Godot 体积雾 | 保留引擎体积散射 | 现有体积雾参数 |
| MakeUp 体积光 | 沿视线指数分布采样场景日月遮挡，并乘云层遮挡 | 默认12步、96m、额外1024²遮挡捕捉 |

MakeUp 两种路径均不自动开启全局体积雾。体积光只响应日月，不表示点光源或多层彩色透射体积散射。

Godot 的内部方向光阴影图未由当前接口直接暴露。当前替代方法是在同一 World3D 中增加正交相机，捕捉场景深度，GPU 转换为线性深度供光束查询；包含真实几何、人物和裁剪植被，不复制权威体素。云通过共享分布单独查询。捕捉是额外场景渲染（仍有引擎几何/材质开销），不是免费复用已有阴影。

遮挡范围默认192m，分辨率512/1024/2048可选；深度偏移默认0.08m。范围外保守无光并淡出，避免没有遮挡数据时穿墙。只包含已驻留渲染几何，不能代替世界流式数据需求。

两个 MakeUp 路径使用独立的抖动、历史重投影、深度拒绝、邻域限制和深度引导放大，不要求开启全局TAA。模式/关键参数/大幅相机变化重置历史。细小遮挡编辑会在历史窗口内收敛，可能短暂残留；不会声称与原包逐像素一致。

## 水下视距控制（2026-09-26）

主世界和样板共用 `game/shading/gdscript/distance_fog.gd`，在「水面 → 水下」调整：

| 设置 | 默认 | 含义 |
|---|---|---|
| 水下可视距离限制 | 开启 | 控制水下距离雾；不改相机裁剪或地图加载范围 |
| 视野衰减率 | 1/12 ≈ 0.08333 /米 | 过渡长度的倒数；0 不衰减，越大过渡越短 |
| 衰减起始距离 | 0 米 | 此距离前不添加距离雾 |
| 水下颜色 | 原有蓝绿色 | 距离雾或无距离衰减时全局滤镜的颜色 |
| 水下染色不透明度 | 0.25 | 关闭视距限制或衰减率为 0 时生效；0 透明，1 完全覆盖 |

使用引擎 smoothstep 平滑过渡，曲线参数保持 1。正衰减率时，过渡终点为「起始距离 + 1 / 衰减率」；例如起点 2 米、衰减率 0.1，则 2 米内清晰、12 米达到最大雾遮蔽。不是逐米固定线性增加。

关闭限制或将衰减率设为 0 时停止水下距离雾，水下期间也不会以室外距离雾代替它；出水后恢复室外雾设置。独立的 Godot 体积雾等效果不由此开关关闭。距离雾关闭时改用同色全局滤镜，不透明度独立可调；不与距离雾叠加。

当前测量相机到片元的距离，未分离跨越水面的水内/水外路径，也未实现水下折射。精确水中路径与曲线仍列入待办。无需新增纹理采样或全屏后处理。

旧 underwater_distance 字段已移除；当前配置格式为 astraeon-shading-20260926-underwater，旧格式明确拒绝并回到默认值。共享水体外观资源同步使用 underwater_attenuation_rate/start；启用开关属于运行策略，不写入外观模板。

验证入口：样板 run_underwater_checks()，使用 tmp/underwater/settings.cfg 隔离设置，报告及截图位于 tmp/underwater。当前检查结果以该报告为准，不是性能基准。

## 无距离衰减时的水下滤镜与颜色弹窗

`underwater_tint.gd` 是场景局部 CanvasLayer（层 -1）与 ColorRect，在三维色调映射之后、HUD 层之前按不透明度混合水下颜色；不采样场景纹理。离开水体、关闭水下效果/水体或不透明度为 0 时隐藏，开启有效距离衰减时也隐藏。平面反射相机不叠加该观察者滤镜。保留当前配置格式，新参数随其它光影偏好保存。

所有光影颜色按钮共用 `game/ui/gdscript/bounded_color_picker.gd`：保留原生 ColorPicker 的颜色信号、旧颜色、数值输入等能力；弹窗在所属窗口内居中并留边，过大的选择器放入可滚动容器。窗口缩放与选择器最小尺寸变化后重新定位。

回归入口仍为 run_underwater_checks()；包括滤镜 0/0.5/1 不透明度、HUD 不染色、出水恢复、距离雾互斥、配置保存，以及底部颜色按钮和短窗口的弹窗范围/滚动验证。未运行正式性能基准。
