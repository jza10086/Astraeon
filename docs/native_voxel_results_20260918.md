# 原生体素首版接入验证（2026-09-18）

Godot 4.7 stable、Windows x64、D3D12 Forward+、RTX 3060 Laptop GPU。编辑器和 template_release 原生 DLL 均编译成功；尚未验证完整导出游戏包。

最终主场景经编辑器重新启动，出生碰撞就绪；通过正常保存退出入口结束，未出现运行错误。

17 项数据检查通过：负坐标确定性、四类地形表层、保存重读、最新副本损坏恢复、错误种子拒绝与双副本损坏拒绝。四组场景测试均通过连续 20 次编辑排队保存后的最新值重读与出生碰撞检查，无 SCRIPT ERROR / ERROR 输出。

默认水平 64、垂直 32、碰撞半径 32；固定条带地形。每组依次以 16、32、64 体素每秒执行直行、反向、转向、传送，每阶段约 1.5 秒。每约 0.25 秒采样，包含测试驱动开销，不视为纯引擎基准。

每组恰有 3 次未就绪采样，均为各次传送后的首次采样，网格与碰撞同时缺失，后续采样恢复。直行、反向和转向采样中未观察到缺失；不能据此证明两个采样之间没有短暂空洞。

四组帧时差异小，未显示预加载的明确优势。开启预加载的新图流式队列峰值略高，生成与写入量略增；保留开关供后续取舍，不宣布胜出方案。测试没有控制硬件热状态和系统帧率限制，不能外推到其他机器或长时间高速移动。

关闭预加载的新图：末次采样累计 4216 次生成约 303ms，4175 次写入约 4872ms。开启：4284 次生成约 308ms，4243 次写入约 4997ms。累计 worker 时间可重叠，不能相加当作主线程耗时。生成计数还包含测试用高度列采样。重读以磁盘加载为主；边界/采样时序可能产生少量新段。

两组世界逻辑文件长度约 156.1／157.1 MiB；双副本固定槽位包含空洞，并非实际磁盘分配量。当前优先简单可靠的无压缩读取，存储空间与逐条落盘开销仍可优化。
