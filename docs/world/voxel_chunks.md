# 世界坐标与加载契约

当前生产接口；制作规格见 [资源规格](../resource_specifications.md)。

## 单位和坐标

- 体素（voxel）：一个方块的数据单元。项目标准方块边长为 1 Godot 单位 = 1 米；材质定义不改变方块占据的体素尺寸。
- 区块（chunk）：XZ水平面上 **16×16体素的区块列**。区块坐标为 `(cx, cz)`，不把高度写入区块尺寸。
- 区块段（section）：区块列内 **16×16×16体素**的垂直分段，坐标为 `(cx, sy, cz)`。当前插件的数据块和网格块均采用这个尺寸；它们是实现术语，不等同于整根区块列。
- 当前生产世界 Y∈[-64,192)，共 256 层；历史 512 层基准不表示最终世界限制。
- `cx=floor(x/16)`，`cz=floor(z/16)`，`sy=floor(y/16)`；局部坐标为世界整数坐标减去段坐标乘16，始终落在0～15。必须向负无穷取整：x=-1→cx=-1、局部15；x=-16→cx=-1、局部0；x=-17→cx=-2、局部15。
- 区块覆盖采用半开区间：[16cx,16(cx+1))×[16cz,16(cz+1))，不重叠、不留缝。

## 加载契约

视距指**水平半径**，不是直径或区块总数。256体素 = 16区块半径，直径约512体素。

加载中心随观察者移动，并向下对齐到16体素网格。以该锚点为圆心，区块水平中心 `(16cx+8,16cz+8)` 与锚点的距离不超过半径时选择该区块列。因此锚点在区块边界交点；观察者与锚点在X、Z各轴上均有小于16体素的量化偏差。采用整区块显示，边缘仍呈阶梯形。

令观察者所在区块为 `(ax,az)`、区块半径为r，精确判定为：

`(2(cx-ax)+1)^2 + (2(cz-az)+1)^2 <= (2r)^2`

r=16时选择812个水平区块列；原盒形为1024列，减少20.70%。这是离散几何覆盖差异，不能直接换算为FPS提升。

垂直半径独立设置为 `vertical_distance`。历史基准使用256体素（上下各16段），按段对齐后裁剪到世界Y边界；**不强制加载整列512层**。相机Y提高时，实际加载的上下段范围随之变化。水平和垂直半径均要求16的整数倍。

网格和碰撞分别采用圆形需求与独立半径。体素数据额外保留一段邻居边框，包括斜向邻居，以保证边缘网格完整；因此数据段数大于可网格化段数，空段也不一定生成可绘制网格。

生产世界已有预测数据预加载、独立碰撞 viewer 与温缓存。具体默认参数见 [原生后端](native_voxel_backend.md)，缓存策略见 [缓存设计](world_cache.md)。

## Section 缓存与光照页

驻留、编辑/保存版本和光照缓存以 16³ section 为单位，不改变 16×16 区块列或 1m 方块契约。保持水平圆形需求与独立垂直范围，缓存保留环只延长既有数据的寿命，不扩大用户视觉视距。当前主世界高度 [-64,192)，天空依赖覆盖完整高度，未知区段作为遮挡。生命周期、页表及预算见 [缓存设计](world_cache.md)。

历史圆形加载的实现与复现见 [基准记录](../../test/voxelgame/reports/circular_loading_20260913.md)。
