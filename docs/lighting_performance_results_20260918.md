## 如何解读本轮结果

GPU 遥测 3336 个样本，温度中位数 87℃，记录范围 62–94℃；其中仅 3 个样本达到或超过 90℃。`clocks_event_reasons.active` 的 0x20 标志在 3255 个样本出现（约 97.6%）；运行期间额外的 NVIDIA 具名查询确认 `sw_thermal_slowdown=Active`、`hw_thermal_slowdown=Not Active`、`sw_power_cap=Not Active`。本轮主要反映持续热负载下的笔记本表现，不能宣称已排除温度干扰。

很多轻负载场景约为 483 FPS，即便 GPU 时间有所增加，整帧中位数仍几乎不变。这个平台的具体原因尚未定位，不能用它证明效果没有成本。FPS 列描述实际整段表现，GPU 列提供另一种观察；GPU 仍是 Godot 视口计时估计，反射计时有异步归属误差。

152 个用例中，143 个帧成本等级为“待定”，128 个 GPU 成本等级为“待定”。“待定”包括差异低于噪声、配对方向不一致和频率漂移，并不等同于低成本或无效果。表格中的其余等级也只是本轮场景下的初筛，不能直接泛化为画质预设。

## 持续组合与编辑

组合启用水面平面反射、日月阴影、方块云、动画人物和 16 个测试光源；其余配置见 manifest。两段依次运行，因此温度差也包含前段运行历史。

| 组合 | 整段 FPS | P95 / P99 帧时间 ms | GPU 时间估计 ms | GPU 温度中位数 | GPU 功耗中位数 |
|---|---:|---:|---:|---:|---:|
| 不限帧，60 秒 | 430.30 | 3.530 / 3.735 | 1.345 | 87℃ | 62.56W |
| 上限 120 FPS，60 秒 | 120.02 | 8.770 / 9.105 | 1.117 | 80℃ | 46.20W |

两段都没有超过 11.11ms 的采样帧。120 FPS 限帧段约一半的帧略长于理想 8.33ms，是需要结合 P95/P99 解读的节奏波动；不能把这一比例直接说成严重掉帧。该段结束时 GPU 温度降至约 75℃，最后遥测不再显示此前温控标志；60 秒不足以证明长期热平衡。

已测 128 方块放置/挖掘预算用例的传播、网格与上传全部完成，完成时间范围 91.06–125.103ms。此数值为整个异步工作完成延迟，不等同于单帧阻塞；逐段同步提交时间与尾帧指标见完整表格。

## 修复验证记录

最初失败由 GDScript 三元表达式构造普通数组、赋给类型化数组引起，静态解析未覆盖此运行时类型错误。已将顺序与索引数组改为显式类型化初始化/assign，并加入完整配对计数、空配对失败判定及 Python 日志错误即时终止机制。设置名称解析也已限定在 UI 标签字典中，避免提示文字覆盖名称。

短测 `tmp/lighting-cost-20260918-smoke-fix1` 耗时 122.7 秒，6 用例强制 ABBA+BAAB，共 12 配对、50 段，退出码 0。随后本轮完整测试再次验证了配对、落盘、计时与报告流程。错误注入和硬超时分支未单独实际触发验收。旧失败目录 `tmp/lighting-cost-20260918-075627` 不参与任何本轮统计。
