# 界面呈现

## 职责与当前进度

设置分类菜单、帧时间 HUD、受限颜色弹窗及水下观察者滤镜已接入。

## 架构与数据流

用户设置 → 光影 profile；帧时间只测 process 间隔；UI 不执行世界缓存计算。

[快捷键与按键映射](../input_mapping.md)、[设置与 HUD](../shading/world_shading.md)、[水下与颜色弹窗](../shading/water_light_shafts.md)。

## 物品栏与快捷栏

新增 game/ui/inventory：底部 10 格快捷栏、居中 3×10 储物区及同源快捷栏；60×60 槽位、4 像素间隙，简单灰色矩形材质。支持 E/Esc、数字 1—0、滚轮、点击取放、拆分/合并、整堆交换和 Shift 快速转移。输入互斥、持久化及范围见 [物品栏](../gameplay/inventory.md)。独立交互入口为 test/inventory/scenes/inventory_sample.tscn。

创造背包采用上方分类标签、右上搜索、右下储物栏，目录左键拿一个、中键拿一组；独立鼠标堆叠跟随指针、不预留槽位，点击实际槽位才放入。关闭背包直接移除手上物品；储物页提供移除格。搜索框隔离 E/数字快捷键。详见 [分类设计](../gameplay/inventory.md#创造选取与分类)。

## 人物选择菜单

主菜单左下角「切换人物」打开人物页；左侧 ScrollContainer 直接以人物名字作为按钮文字，内容溢出时支持鼠标滚轮和焦点跟随；右侧独立 3D 视口播放所选人物 Idle。内置目录为标准素体与 Klukai，另展示用户人物文件夹中校验通过的 GLB。

已使用人物的名字按钮右下角显示「当前使用」，预览该人物时底部按钮显示「当前使用」并保持按下状态；其他人物显示「使用此人物」。保存成功后留在页面并立即更新标记；「返回」或 Esc 退出页面并恢复左下角按钮焦点，未保存的预览不写入配置。没有底部常驻说明文字，错误提示仅在失败时显示。主菜单加载世界期间入口禁用。该页面只由主菜单创建，不出现在暂停或游戏内设置中；重新进入世界时使用已保存人物。保存失败保留页面和错误提示。顶部「导入人物」选择自包含 GLB，校验后复制到 `user://characters/` 并预览，不自动使用；「打开人物文件夹」打开该目录，可直接放入 GLB，重新打开人物菜单时扫描。文件名作为名字，无需代码登记。同名同内容不重复复制，同名不同内容拒绝覆盖；失败显示原因并保留原文件。「删除」对内置人物保存隐藏状态，对用户人物删除目录中的对应 GLB，不删除原始来源文件。删除当前人物自动选择剩余项，最后一个人物不可删除。内置隐藏记录在用户设置内，本阶段没有恢复入口。文件扫描不递归、不持续监听；人物较多时第一次校验会短暂占用主线程。最新状态与删除验证见 [人物菜单控件](../../test/ui/reports/2026-09-27_character_controls.md)。初始验证与分辨率覆盖见 [模型选择回归](../../test/ui/reports/2026-09-27_character_selection.md)。

最新轻量验收见 [外部人物导入](../../test/ui/reports/2026-09-27_character_import.md)。
