# 界面呈现

## 职责与当前进度

主界面、设置分类菜单、帧时间 HUD、受限颜色弹窗及水下观察者滤镜已接入。

## 主界面布局与交互

入口：`game/ui/main_menu/scenes/main_menu.tscn`，控制器位于相邻 gdscript 目录。F5 先进入此场景；单人游戏先打开存档选择页，再异步加载 `game/core/main.tscn`。多人按钮标注「暂未开放」并禁用。

参考 Minecraft 的居中标题和纵向长按钮结构。1920×1080 基线采用 canvas_items / expand / fractional：标题位于高度 22%，主按钮组从 48% 开始。单人和多人按钮为 600×72，间隔 16；设置与退出均为 292×64，两者间隔 16，上方额外留白 24。底部边距 40 / 28，放开发状态和键盘提示。界面使用纯色、矩形描边和明确的悬停／按下／禁用／焦点状态，不确定最终 UI 材质。

设置页宽 960、高度为视口的 84%，固定标题与底部操作，中部独立滚动并跟随键盘焦点。复用现有光影设置绑定，编辑独立 profile 副本；保存成功后返回，取消不写盘，读取／保存失败保留可见提示。测试夹具选项不展示；地图缓存设置仍只在世界中提供。标题页没有世界预览，画面设置在进入世界时应用。

主界面默认焦点为单人游戏；隐藏页不接收焦点。返回设置恢复到设置按钮。退出弹窗默认选择取消；加载期间按钮锁定并显示进度，失败恢复操作。操作依据见 [输入映射](../input_mapping.md)。

## 单人游戏暂停菜单

`game/ui/pause_menu/scenes/pause_menu.tscn` 由世界场景局部创建，使用主界面共享的 `game/ui/resources/menu_theme.tres`。半透明遮罩上纵向排列三个 600×72 按钮：回到游戏、设置、返回标题界面。默认聚焦回到游戏。

Esc 暂停场景树并禁用玩家输入，再按 Esc 或点击回到游戏恢复。背包打开时 Esc 先关闭背包。设置沿用世界中的即时应用／保存设置和缓存控制；设置页居中、独立滚动，Esc/F6/返回按钮回到暂停菜单并还原设置按钮焦点。标题页设置仍采用保存／取消草稿，两种语义明确区分。

返回标题等待世界保存完成后再切换场景。保存期间按钮锁定，保存失败报错并停止世界，隐藏暂停菜单，禁止重试或继续；成功后释放世界资源、恢复场景树与窗口关闭行为，标题页鼠标保持可见。没有增加 autoload 或第二份世界状态。

## 架构与数据流

单人存档页由 `world_select.gd` 呈现，`game/core/gdscript/world_selection.gd` 负责列举、选择、命名创建和删除。列表来自 `runtime_data/worlds` 的直接子目录，默认选中上次使用的存档；空列表禁用读取／删除，双击或 Enter 可读取。页面宽 1200、高度为视口 84%，列表伸展滚动，下方两行操作各等分宽度。

创建页填写 1–64 字名称，拒绝重复、路径符号及 Windows 保留名称；创建并进入独立世界目录，沿用当前人物和内容包，支持填写有符号 32 位整数种子（-2147483648～2147483647），留空则随机生成；创建时写入存档目录的 world.cfg，读取时恢复 seed 与 biome_layout。名称即目录名，不新增地形格式或存档转换。已有目录继续由原生世界检查注册表、版本与内容；旧原型格式仍拒绝读取，列表发现不等于内容校验通过。

删除确认显示准确名称及不可撤销提示，默认聚焦保留存档；执行前检查完整目录树，拒绝链接与路径越界，只删除选中目录并刷新列表。已选择项同步从 settings.cfg 清除，其他设置保留；失败留在列表显示原因。加载时禁用重复操作。创建页 Esc 返回列表，列表 Esc 返回标题；删除弹窗 Esc 取消。

用户设置 → 光影 profile；帧时间只测 process 间隔；UI 不执行世界缓存计算。

## 物品栏与快捷栏

新增 game/ui/inventory：底部 10 格快捷栏、居中 3×10 储物区及同源快捷栏；60×60 槽位、4 像素间隙，简单灰色矩形材质。支持 E/Esc、数字 1—0、滚轮、点击取放、拆分/合并、整堆交换和 Shift 快速转移。输入互斥、持久化及范围见 [物品栏](../gameplay/inventory.md)。独立交互入口为 test/inventory/scenes/inventory_sample.tscn。

创造背包采用上方分类标签、右上搜索、右下储物栏，目录左键拿一个、中键拿一组；独立鼠标堆叠跟随指针、不预留槽位，点击实际槽位才放入。主世界关闭背包将手上物品丢到地面；储物页移除格仍直接删除。搜索框隔离 E/数字快捷键。详见 [分类设计](../gameplay/inventory.md#创造选取与分类)。

## 人物选择菜单

主菜单左下角「切换人物」打开人物页；左侧 ScrollContainer 每个人物文件夹一个按钮，文字为文件夹与 GLB 的共同前缀，支持滚轮与焦点跟随。右侧同时显示第三人称全身 Idle 和固定 16:9 第一人称 FP_Idle 双预览。默认人物与导入人物均来自 external_data/characters，没有独立内置列表。

已使用人物按钮右下角显示「当前使用」，底部使用按钮显示同文本并保持按下状态；预览其他人物时显示「使用此人物」。保存后立即更新标记；返回或 Esc 退出并恢复入口焦点，单纯预览不写配置。顶部导入选择包含同名前缀 `_tp.glb` 与 `_fp.glb` 的人物文件夹，校验后成对复制并预览，不自动使用；打开人物文件夹定位所选目录。删除移除该目录中的两模型，来源不变；包含其他文件时拒绝删除，最后一个人物受保护。删除当前人物先保存剩余选择。无底部常驻说明，失败显示原因。只允许在主菜单选择，加载世界期间入口禁用；关闭页时释放双预览。扫描在打开页面时进行，不持续监听。

主菜单新增 Content Packages 安装/启用面板；物品图标按可见性申请与释放内容缓存引用。缓存二级菜单显示视觉CPU/GPU载荷、读取/上传、回收和错误。

最新验收见 [成对人物与独立第一人称](../../test/entities/reports/2026-09-27_paired_character_models.md)，包括四种分辨率布局检查。此前单 GLB 报告仅为历史记录。

## 十字准星

主世界 CrosshairLayer 在视口中心显示白色细十字、黑色描边和中心留空；1080p UI 基线下主体跨度 24、线宽 2，随 UI 缩放与窗口尺寸居中。第一／第三人称共用相机中心交互射线。世界就绪、玩家输入启用且鼠标捕获时显示；暂停、设置、背包、加载或错误状态隐藏。Control 不接收鼠标，不影响挖掘／放置操作。入口：game/ui/gdscript/crosshair.gd。

设置顶部提供「物品投掷 · 扔出力度（m/s）」：主菜单沿用保存／取消，暂停设置有独立保存按钮。默认 6，范围 1–20；同时提供「挖掘掉落 · 朝玩家力度（m/s）」，默认 0、范围 0–10；暂停页通过「保存投掷与掉落设置」保存。规则与持久化见 [掉落物](../entities/dropped_items.md#扔出力度设置)。

## 生存与创造模式

创建页默认生存，可选创造；暂停菜单可切换模式并保留暂停。两种模式共用快捷栏，生存隐藏创造目录与删除功能。两条矩形生命/饱食度条显示当前值/10，背包打开时隐藏。见 [模式与状态](../gameplay/modes.md)。
