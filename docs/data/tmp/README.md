# 静态内容定义临时研究

此目录参与 Git，保存调查报告、算法研究、备选方案和阶段计划，不保存运行日志、生成世界或二进制。

文件名：YYYY-MM-DD_topic.md。正文标注日期、状态、适用版本或代码依据、结论和相关链接。状态使用：研究中、待决策、已采纳、已否决、已过时。

采纳后把当前结论写入 [模块正式文档](../README.md)，在研究文档记录采纳位置；历史研究不能覆盖正式规则。测试证据归 test/<测试项>/reports，原始输出归根 tmp。
