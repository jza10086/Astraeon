# Basic Voxel 资产核对记录

日期：2026-09-26。历史验证证据，非本次整理重跑。

## 核对与验收

本次直接解析正式 GLB，核对了哈希、19 骨骼及父子关系、六动作名称与时长、八形态键、每个动作的形态权重通道及 8 权重布局，与说明一致。

制作项目的六动作交付报告记录：Blender 重导入抽样最大顶点偏差约 0.740 mm；Godot 4.7 独立项目检查了 126 个姿态样本、Root 固定和形态轨道。这是外部报告，不代表本次在 Astraeon 重跑或完成人工验收。

后续接入需验收尺寸、朝向、静止姿态、Root 固定、循环、肩部混合、速度匹配、真实起跳/下落/接地，以及地面、墙、斜坡、平台、低顶、边缘下落与相机遮挡。源模型已知肘膝大角度内折仍有网格重叠；衣物穿插、极端混合、滑脚和手感需人工检查。
