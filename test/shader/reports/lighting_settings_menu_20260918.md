# 设置菜单、自发光与云分支清理

2026-09-18，独立光照样板，Forward+ / D3D12。启动方式仍是 `./test/shader/runners/lighting_sample.ps1 -Run`，然后点击“创建光照样板”。

## 操作

顶部页面选择“参数设置”或“场景操作与观察”。参数设置先选一级分类，再选二级模块：

| 一级分类 | 二级模块 |
|---|---|
| 光照 | 时间与天空、环境光与 AO、局部照明、方块自发光、阴影 |
| 水面 | 水体与天空反射、波纹、场景反射、水下 |
| 环境 | 距离雾、植被、方块云 |
| 显示与测试 | 画面与帧率、人物与批量光源、传播预算 |

效果开关统一使用下拉选项，不再使用独立开关按钮。水体选择关闭 / 统一水色 / 逐像素深度吸收；场景反射选择关闭 / SSR / 平面反射；云选择关闭 / 方块体积云 / 方块体积云＋日月云影；人物选择关闭 / 静止 / 动画。局部照明保留五种方案，其中关闭局部照明仍显示方块自身发光。阴影边缘选择软 / 硬，日月阴影的启用仍独立于局部点光源。

选择方案后即时更新材质、捕捉状态、相关控件的值和显隐。例如 SSR 下隐藏全部平面反射参数，硬阴影隐藏软滤波参数，统一水色隐藏深度吸收参数。关闭水体停止水下效果和反射捕捉；重新开启使用保留的子设置。切换不重置其他方案的数值，不暗中套用品质预设。恢复默认保留体素编辑，并同步刷新菜单。

云影只影响日月直射；关闭直射时云影强度/柔度隐藏。菜单中参数数量较多的模块可以纵向滚动。

## 自发光

原灯块是 unshaded 材质，却把倍率写入 EMISSION，实际可见输出没有随倍率变化。现在直接输出 `ALBEDO = lamp_color * lamp_emission_strength`，保留 HDR 值。倍率 0 为黑，增大后变亮；颜色拾取器中的 HDR 强度也会乘入结果，常规调节使用白色/色相配合独立倍率即可。

自发光、照亮周围的点光源/体素光、Bloom 仍分别控制。降低自发光到 0 不移除光源，也不改变传播。Filmic 色调映射会压缩高亮，因此屏幕亮度不会严格按倍率线性增长。

## 删除与配置

完全删除写实简化体积云着色器及 UID、天空噪声纹理初始化、专属时钟更新和步数/变形字段。天空只使用简单渐变，云只保留方块几何与可选云影。

配置仅支持 `lighting.format = astraeon-lighting-20260917`；旧配置及未知字段明确拒绝读取，使用默认值并显示提示。首次启动没有文件则直接采用默认值。用户调整设置或恢复默认时保存当前格式，通过临时文件完成写入后替换目标；不再提供旧 SSR 属性别名、旧 lighting_p0 读取或迁移转换。测试使用 tmp 下独立文件，不覆盖用户设置。
