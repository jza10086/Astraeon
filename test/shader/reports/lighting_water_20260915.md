# 水面调节与屏幕空间反射

2026-09-15；独立光照样板。用户本轮明确要求 SSR，替代此前“不加入 SSR”的阶段限制；仍不加入折射、流体模拟或大世界水系统。

## 操作

启动 `./test/shader/runners/lighting_sample.ps1 -Run`，创建样板后点击“水面倒影观察”。水池北岸新增三个彩色观察柱，与现有建筑一起用于对照倒影；观察柱仅为样板可视网格，不是可编辑体素或碰撞对象。

左侧滚动面板的“P2 · 水”“水面 · 屏幕空间反射”“水下”提供以下设置，自动写入嵌套项目的 `user://settings.cfg`。缺少的新字段采用默认值，已有偏好保留，恢复默认可整体重置。

| 参数 | 默认 | 用途 |
|---|---|---|
| 浅水 / 深水颜色 | 青绿 / 深蓝 | RGB 颜色选择器；深度吸收时随厚度混合 |
| 水体吸收 | 0.22 | 增大后更快进入深水色并变得不透明 |
| 水体不透明度 | 1 | 缩放原吸收透明度；反射仍独立存在 |
| 低画质基础不透明度 | 0.65 | 统一水色模式的基础透明度 |
| 水面粗糙度 | 0.22 | 控制直射高光宽度和 SSR 颜色 mip 模糊 |
| 直射高光强度 | 0.45 | 日月 / 点光源高光强度 |
| 波纹强度 / 密度 / 速度 | 0.12 / 1 / 1 | 几何波幅、频率、时间推进；速度 0 冻结当前波形 |
| 天空反射开关 / 强度 | 开 / 1 | SSR 未命中时的天空色近似，也可独立关闭 |
| SSR 开关 / 强度 | 开 / 1 | 仅水面启用；强度 0 等同切回基础 shader |
| SSR 质量 | 中，32 步 | 低 16 / 中 32 / 高 64；提高可减少漏采细物体 |
| SSR 最大距离 | 48 | 反射射线长度上限，末段淡出 |
| SSR 命中容差 | 0.3 | 单层深度的厚度近似；过大容易出现错误命中 |
| SSR 屏幕边缘淡出 | 0.08 | 按命中 UV 到屏幕边缘的距离淡出 |
| 水下颜色 / 可视距离 | 蓝绿 / 12 | 进入水体后的雾色和衰减距离 |

## 实现与开销边界

Godot 内置 Environment SSR 不显示在 alpha 混合材质上，因此保留透明水，采用水面专用视空间射线追踪。[Godot 材质文档](https://docs.godotengine.org/en/4.4/tutorials/3d/standard_material_3d.html) 与 [环境文档](https://docs.godotengine.org/en/4.6/tutorials/3d/environment_and_post_processing.html) 说明透明材质和屏幕空间信息的限制。

`water_surface.gdshaderinc` 共用吸收、波纹、Fresnel 与高光代码；`water_reflective.gdshader` 才声明屏幕颜色纹理并编译 SSR 路径。关闭 SSR、强度设为 0 或隐藏水面时切回 `water.gdshader`，不为该水材质请求屏幕颜色复制 / mip。深度吸收仍是每像素一次深度取样；SSR 另加最多 16 / 32 / 64 次步进，遇到首次穿越后最多再取 6 次深度作五轮细化和验证，并读取一次颜色。步进提前终止，无每帧 CPU 射线检测。

按波纹法线反射视线，沿射线读取当前帧不透明深度；命中颜色按 Fresnel 混合，未命中或靠近屏幕边缘时回退到已有天空色。波纹解析法线同步密度调整，并扩展水面剔除边界。天空反射、SSR、波纹、吸收画质互不暗中启用；低画质统一水色并不会自动关闭用户开启的 SSR。

限制：屏幕外、被遮挡的物体以及透明对象没有可用颜色 / 深度；薄物体和低档大步长仍可能漏采。没有独立历史缓存、时域重投影、Hi-Z、锥追踪或半分辨率反射；粗糙度 mip 只是廉价模糊，不能当作物理粗糙反射。镜头移动或物体出入屏幕仍可能出现反射消失与边缘跳变。水下背面不追踪 SSR。天空回退仍是共享昼夜颜色，不是完整云天空贴图反射。有限水池边界 / 池底和单层深度近似沿用原样板。
