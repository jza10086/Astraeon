# 平面反射与显式调节参数

2026-09-15。仅作用于独立光照样板；本轮实现平面反射，并按用户要求取消界面的低 / 中 / 高预设。后续由人工评估决定预设组合。

## 使用

运行 `./test/shader/runners/lighting_sample.ps1 -Run`，点击创建样板，再点击“水面倒影观察”。在“水面 · 场景反射”中选择 **关闭 / SSR / 平面反射**。这些是互斥的技术路线，不是画质档位；天空反射仍有独立开关。所有配置资源的导出字段均有面板控件，保留保存、重载和恢复默认。

默认选择平面反射，宽高倍率 0.5、每帧更新。当前只接受明确的反射方案与步数配置，不保留旧 SSR 开关、质量档位别名或迁移。设置菜单根据反射方案隐藏不适用参数。

## 平面反射参数

| 控件 | 范围 | 默认 / 含义 |
|---|---|---|
| 平面反射强度 | 0–1 | 1；设为 0 停止捕捉并回退基础材质 |
| 反射宽高倍率 | 0.1–1 | 0.5；1080p 下为 960×540，像素数 1/4 |
| 反射更新 Hz | 0–120 | 0 = 每帧；正数是更新上限，受实际帧率限制 |
| 反射距离 | 16–1600 米 | 256；镜像相机远裁剪，不限制天空背景 |
| 水位裁剪偏移 | −0.2–0.3 米 | 0.02；相对水位 0.75 米，正值剔除更多岸边 |
| 波纹倒影扰动 | 0–0.1 | 0.015；按法线偏移倒影 UV，0 保持严格平面投影 |
| 倒影模糊半径 | 0–6 反射纹理像素 | 0；非零采用四点滤波，与水面粗糙度独立 |
| 倒影边缘淡出 | 0.001–0.2 UV | 0.02；捕捉纹理边缘过渡到天空回退 |
| 倒影抗锯齿 | 关闭 / FXAA | FXAA；与主视图 AA 独立 |
| 水面离屏停止更新 | 开关 | 开启；水池与主相机视锥完全不相交时暂停 |
| 倒影包含植被 | 开关 | 开启；控制草和树叶，树干及其阴影仍可存在 |
| 倒影包含方块云 | 开关 | 开启；程序化天空云属于天空背景，遵循全局云设置 |
| 倒影距离雾 | 开关 | 开启；同时需要全局距离雾开启 |

主面板顶部显示实际捕捉尺寸、配置的更新频率和更新 / 暂停状态。关键参数附悬停说明。低频率下相机矩阵与捕捉纹理一起更新，避免把旧图像当作新相机图像，但动态对象和视野覆盖仍会滞后。

## SSR 及原有设置

SSR 现在直接调节：步进次数 **4–128**（默认 32）、命中细化次数 **0–8**（默认 5）、法线起点偏移 **0–0.3 米**（默认 0.06），以及原有强度、距离、命中容差和边缘淡出。不再用低 / 中 / 高打包这些参数。

水色方式改名为“统一水色 / 逐像素深度吸收”；对应的不透明度明确称为“统一水色不透明度”。水色、吸收、高光、波纹、水下衰减等仍独立调节，见 [前一轮水面说明](lighting_water_20260915.md)。

阴影滤波改为明确的 **1 / 4 / 8 / 16 / 32 采样**选择，默认 8 采样；硬阴影、模糊半径、贴图分辨率、距离和偏移仍独立。这里只能选择引擎支持的滤波核，不能填写任意阴影采样数；引擎会按滤波核调整半径，开启面光源时另有半影采样。[当前引擎对应实现](https://raw.githubusercontent.com/godotengine/godot/4.7-stable/servers/rendering/renderer_rd/renderer_scene_render_rd.cpp)。其内部枚举不是游戏画质预设。

原先没有面板入口的昼夜周期、方块光颜色 / 曲线 / 补光系数、传播预算也已显示。影响世界传播调度的预算参数与纯材质视觉参数分组区分。

## 实现与限制

`planar_reflection.gd` 是样板局部节点：共享当前 World3D，用镜像相机捕捉，固定平面 y=0.75。捕捉纹理采用 HDR，捕捉环境使用线性色调映射、曝光 1、禁用 Glow；最终曝光 / 色调映射 / Glow 由主视图统一完成。日月、点光源与其阴影使用同一场景，不复制世界。镜像相机看得到主相机屏幕外的几何。

当前引擎运行时探针确认没有自定义斜近裁剪投影 API。因此方块、植物、发光方块的材质仅在反射相机中裁掉水位以下片元。样板保留层：17 为方块云，18 为草，19 为水面，20 为反射相机标志；主相机不包含第 20 层，反射相机完全排除水面层以防递归。后续新增被反射材质也必须接入裁剪。草由相机层剔除，树叶因与区段共用网格而在材质中剔除，不等于完全消除树叶绘制提交。

镜面捕捉本身准确对应参考平面；波纹只做轻量倒影扰动，不是弯曲水面的真实光线追踪。四点模糊也不是物理粗糙反射。多个不同水位尚未实现。水下暂停平面反射，离开水面后自动恢复。程序化云背景跟随共享天空；方块云可在捕捉中单独剔除。

关闭 / SSR 模式、平面反射强度为零、水面隐藏时均停止平面捕捉；基础 / SSR / 平面三个 shader 分别选择所需纹理路径。关闭后保留已分配的捕捉资源便于再次开启。额外渲染、裁剪带来的提前深度测试限制、阴影绘制和 HDR 带宽都需要后续实测；分辨率减半不意味着总开销只有四分之一。

## 验证

Godot 4.7 stable / Forward+ / D3D12 / RTX 3060 Laptop GPU。导入通过；平面反射实际渲染 **230 项检查通过**，SSR / 水面回归 **127 项通过**，主视图环境光、局部光源和云阴影回归 **136 项通过**，各日志无脚本 / shader 错误。包括：离屏参照点在镜像视锥中、同一高亮几何在水下被裁掉且移到水上后进入捕捉、限频在环境参数更新时仍生效、关闭 / 离屏 / 水下暂停恢复、任意步数与参数保存、当时的配置迁移（现已删除）、所有导出设置都有控件。

截图覆盖 1920×1080、2560×1440、3840×2160、2560×1080，以及 0.25 / 0.5 / 1.0 捕捉倍率、模糊、波纹、夜间和水下。产物在 `tmp/planar/`、`tmp/planar-ssr-regression/`；日志 `tmp/planar-render.log`、`tmp/planar-ssr-regression.log`。测试单独保存配置，不覆盖用户偏好。
