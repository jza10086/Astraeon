# 模式与玩家状态测试

- `scenes/player_state_test.tscn`：数值 API、权限、共享持物、状态与地形日志往返、损坏恢复、旧格式拒绝、掉落物共同事务。
- `scenes/modes_world_test.tscn`：正式主世界模式切换、放置/破坏规则、飞行/碰撞、四分辨率 HUD、保存及失败原子性。
- `gdscript/world_fixture.gd`：测试新世界显式写入当前创建参数，不迁移已存在文件。

在已验证的项目编辑器中运行对应场景。使用独立 `tmp/` 世界，不改用户存档。失败注入会故意触发一次世界停止错误，测试需验证物品与掉落池未部分发布。图形检查与人工操控手感分别记录。
