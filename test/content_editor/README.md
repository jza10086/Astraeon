# 专用内容编辑器验证

实现说明：[内容编辑器](../../docs/tooling/content_editor.md)。不启动世界，不写原版源资源，不采集性能基准。

```powershell
./test/content_editor/run.ps1 -Mode Session
./test/content_editor/run.ps1 -Mode Render
```

复用项目 Godot 版本解析器；运行前按 AGENTS.md 确认编辑器 / 导入路线。此入口仅启动有 PID、开始时间、路径和用途记录的测试游戏，不启动第二个编辑器或执行冷导入。超时只关闭身份匹配的自有进程。日志、临时工程、包和截图写 `tmp/content/`。

- Session：原版 / 示例包私有副本、撤销 / 重做、外部文件冲突、六面 / UV / 状态、关联物品、保存 / 重载 / 导出、移出保留文件、图片路径和缺失图片。
- Render：真实主工作区 Control、原生编译与网格材质、两组裂纹、裁剪树叶、自发光、物品图标、水体、双向关联跳转、隐藏 / 暂停、颜色弹窗与多尺寸布局。截图必须另做视觉检查，断言成功不能替代检查画面。
- `gdscript/editor_refresh.gd` 仅为本次开发验证辅助：已有编辑器中资源脚本缓存过旧时，先确认没有未保存内容工程并停用本插件，再刷新明确列出的工具依赖和场景，重新启用；不重启 / 终止编辑器，不改场景，不用于运行时自动补救，也不替代 DLL 重启要求。

验收证据见 [2026-09-27 报告](reports/2026-09-27/README.md)。
