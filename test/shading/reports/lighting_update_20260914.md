# 光照样板：已确认方案与调试控件更新

日期：2026-09-14。后续更新：[2026-09-15 环境光平滑与方块云分支](lighting_environment_clouds_20260915.md)；本文保留本轮实现记录。仅涉及 benchmarks/voxelgame/project/astraeon_lighting/；主游戏和原性能基准保持原状。

## 面板使用

使用 `./test/shading/runners/lighting_sample.ps1 -Run` 打开，点击“创建光照样板”。左侧向下滚动查看设置，右上角独立显示 FPS 与平均帧间隔（每 0.5 秒更新，包含限帧等待，并非纯 GPU 时间）。

| 设置 | 默认 | 范围与作用 |
|---|---|---|
| 日月阴影 | 开 | 控制太阳/月亮阴影；局部点光源始终保留遮挡 |
| 硬阴影 | 关 | 硬模式使用引擎 HARD 过滤；软模式使用低/中/高过滤质量；同时应用到日月和局部灯光 |
| 阴影模糊半径 | 1.0 | 0–4，Godot shadow_blur 倍率，不是米或像素；硬模式暂时忽略，切回软模式恢复 |
| 日月阴影贴图 | 4096 | 1024/2048/4096/8192，整张方向光图集尺寸；不等于每个级联的尺寸，不修改局部灯光图集 |
| 阴影偏移 / 法线偏移 | 0.06 / 1.7 | 日月光参数；局部点光源单独使用 0.05 / 1.0 |
| FPS 显示 | 开 | 独立于滚动面板，可关闭 |
| 最大 FPS | 0 | 0 不限；1–360；使用 Engine.max_fps，不修改物理 tick |
| 垂直同步 | 关 | 独立开关；开启后实际帧率还受显示器刷新率约束 |

所有字段保存到嵌套工程 user://settings.cfg；旧文件缺失新字段时保留默认，既有偏好继续优先。恢复默认恢复整个光影配置，不清除体素编辑。更换图集分辨率可能出现一次分配/重建停顿，不属于常态 FPS。方向光图集和过滤是 RenderingServer 进程级设置，当前限定单一光照样板；退出场景恢复此前的帧率上限和垂直同步。

## 水体厚度吸收

标准画质对水面每像素单次读取不透明场景深度，通过 Forward+ / D3D12 的 reverse-Z 逆投影恢复交点，以视线长度计算吸收与透明度。同一材质逻辑覆盖浅/深水两半网格，取消每半池固定水深。低画质直接使用统一水色和透明度，不执行深度采样分支。波纹、天空反射、水下表现仍各自独立。

深度无效时按有限水池边界截断视线；正常深度也限制在水池范围内。透明物体不提供可靠不透明深度，不能用于透明层之间的精确吸收；水下继续由已知水体边界与环境雾处理，水面背面使用简化颜色。波浪附近固定水体边界属于近似。无折射、SSR 或流体模拟。

## 局部光源与弱补光

每个发光方块建立一个 OmniLight3D，中心点近似发光位置，阴影负责墙体/孔口遮挡；默认强度 4、范围 12。灯光节点按实际体素编辑增删，不逐帧扫描。材质区分 LIGHT_IS_DIRECTIONAL，只有日月直射受天空可见度约束，局部点光源在密闭室内可以正常工作。尚无定向灯具，因此没有额外实例化聚光灯。

发光外壳单独绘制，不投射阴影，避免外壳遮住自身中心光源；因此该外壳也不会遮挡其他实时光源，这是有限样板的近似。其权威体素仍为不透明，参与原光传播。关闭局部直射只将能量设为零，外壳自发光和 Bloom 开关保持独立。

原方块传播光降为默认 0.04 的弱补光，可独立关闭；按表面切平面插值，拒绝实心邻居，对角邻居要求两侧空气连通。它不会跨墙法线混合，也不是物理 GI；经孔绕行仍可能形成弱间接亮度。世界传播算法保持原样。

显示纹理由 RG8 扩展为 RGBA8：R 天空光、G 方块光、B 空气占用、A 保留。完整 64³ 上传由 512 KiB 变为 1 MiB，仍只在传播收敛后发布。材质仅在补光启用且强度非零时做额外插值。编辑到网格/光纹理发布仍非原子同步，短暂过渡与全量打包开销属于后续优化项。

## MakeUp 式简化体积云

单层云位于 Y=90–120，以 Godot 生成的可平铺二维噪声控制上下边界；半分辨率、默认 24 步（8–48 可调），累计透明度并用高度近似明暗。覆盖率与移动速度复用原设置；动态形变默认关闭，开启增加第二次噪声读取。屏幕固定抖动和远处 mip 采样减少步进层纹；没有自定义时域历史。

云色跟随同一昼夜参数。关闭后停止云时钟和密度计算；半分辨率透明通道/合成仍有基本成本。辐射立方体分支跳过昂贵云计算。没有地面云影、完整三维侵蚀、真实自阴影、多次散射或穿云体验；低步数可能有噪点与远处残余层纹。当前水面天空反射仍不包含云的轮廓。

## 验证与已知限制

Godot 4.7 / Forward+ / D3D12 最终检查：完整导入通过，配置检查 59 项断言通过，资源检查通过，光传播回归 61 项通过，实际渲染组合检查 120 项断言通过；最终日志无 SCRIPT ERROR、SHADER ERROR 或 ERROR。截图覆盖 1080p、1440p、4K 和 2560×1080 超宽屏（真实 SubViewport 渲染，不等同物理显示器验收）。

日志与截图位于 tmp/lighting-update/ 及 tmp/lighting-update-*.log。配置检查覆盖非默认设置保存/读取，渲染检查覆盖控件应用、硬/软切换、分辨率变化、限帧恢复、水面画质、云开关/形变、单孔/密闭局部光、补光开关、昼夜、全关与高分辨率面板。

本轮是功能与短时画面检查，不是正式 FPS 基准；截图上的帧率包含测试 SubViewport、窗口合成及场景切换影响，不能用于生产性能结论。点光源数量尚无生产级分配策略；大量光源、全量光纹理打包、云画质与性能统一优化仍待后续安排。
