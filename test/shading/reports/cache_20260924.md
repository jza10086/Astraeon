# 地图与光照缓存验收（2026-09-24）

当前实现已接入主世界，1080p、64/256 视距两轮反转顺序对照通过本轮数值门槛；编辑器重启后的完整导入仍待完成。缓存热路径为 C++，GDScript 负责配置、装配和测试。没有修改地图存档格式或删除用户存档，没有降低本次对照中的阴影、反射或其他光影质量。

## 实现与范围

- 原权威 VoxelData 中保留温 section；生命周期、数据版本、保存完成版本和网格依赖共同防止过期结果覆盖。
- Region 文件句柄受限缓存，同 Region 串行、跨 Region 并行；继续使用双记录、CRC、持久化确认。
- 完整世界高度的 section 增量天空光/单色方块光、世界坐标天气缓存、静态光源索引；旧全量求解器仅保留在测试目录，发布版不编译。
- GPU 逻辑页 16 KiB、默认 256 页合并一个数组层，增量更新；先撤销旧映射再复用槽位，新的几何等待有效页。已显示内容保留上一版有效光照。
- 共用主线程软预算、上传字节上限、后台传播切片、碰撞优先和等待老化；F6 中提供数值设置与统计。

具体接口、预算口径和复现入口见 [缓存文档](../../../docs/world_cache.md)。CPU 占用为受管理载荷和已跟踪临时数据，不是整个进程内存；初始化尚未完成的统计不是零占用证明。GPU 天气池另占 4 MiB。

## 近处编辑可见延迟

此项独立运行，不与 FPS 基准混测。读取邻接像素的 GPU 方块光值，同时观察实际 OmniLight3D 的能量状态。GPU 每 50ms 轮询一次，表中的“已观察到”是上界，不是精确完成时间。

| 视距 | 操作 | 最后一次未更新 / ms | GPU 已观察到变化 / ms | 实时点光变化 / ms |
|---|---|---:|---:|---:|
| 64 | 放置 | 4.3 | 63.3 | 58.4 |
| 64 | 删除 | 4.6 | 58.6 | 103.5 |
| 256 | 放置 | 5.5 | 67.1 | 34.6 |
| 256 | 删除 | 5.2 | 66.7 | 155.8 |

这些是静止且地图稳定时的单次近处编辑，不能外推为所有运动、批量编辑的延迟上限。连续运动矩阵另外报告批次年龄及停止后收敛；批次年龄从未收敛批次的首次失效计时，不能直接当作某一个新编辑的等待时间。

### 剩余长帧与软预算

- 256 视距测量期间缓存协调入口最大 3.30ms，渲染线程页上传累计峰值 0.227ms，没有整片光场快照或整片光纹理重建。
- 仍有超过 2ms 的不可中断调用：网格/碰撞提交累计峰值 7.66ms，网格/碰撞释放峰值 6.99ms。位置为 Voxel Tools 固定 LOD 的提交/释放任务。
- 缓存维护统计含释放通知与锁等待，累计峰值 22.28ms，位于 `VoxelTerrain::_process` 的缓存维护段；已定位，但不能将其描述成严格满足 2ms。后台传播片也属于软预算，实际峰值保留在证据中。
- 连续运动仍有约 20–35ms 的长帧；本轮消除了旧式整片光照造成的主要停顿，没有证明全部引擎/驱动/系统长帧已消失。首次编译帧不剔除。

## 矩阵之后的边界补修

大缓存压力测试发现天气上传等待队列达到 2048 后，生产者可能丢弃新结果，错误地显示全部收敛。已将该结果保留为待发布，随后大缓存压力和恢复通过。三次世界生命周期检查中，每次纹理占用从 269,828,096 降到 124,805,120 byte，原生体素使用量归零；内存池保留空间单独记录，不声称整个进程占用归零。

完整矩阵测量的编辑器 DLL 为 `552036560cda…`，补修版为 `ea71be483c1a…`，发布版为 `a262c2f56145…`。四次新版测量的天气等待队列峰值分别为 90、80、951、288，均未触发 2048 满载分支。另将隐藏面板的“发布延迟”明确标为“光照批次年龄”，并展示天气上传等待数。完整矩阵未伪标为补修二进制重新运行；最终版本的 64/256 短时路径、四种画布面板和发布版 ABI 复核均通过，证据中保留两套指纹。

## 验证边界

- 显卡为 RTX 3060 Laptop，测试期间 GPU 温度最高 91°C，降频标记包含 0x20。保存 GPU 温度、频率、功耗与降频标记；没有 CPU 温度数据。ABBA 减轻顺序偏差，不能消除全部笔记本热状态差异。
- 不以平均 FPS 掩盖 P99、最大帧及更新延迟；首次管线编译帧保留在统计内。
- 原工程旧编辑器尚未重启，本轮使用独立运行进程加载新 DLL。根据项目 AGENTS.md，不在同一工程编辑器仍打开时另开完整导入；编辑器重新导入验收尚待关闭旧编辑器后完成。
- 当前验收高度为 [-64,192)，不代表最终 512m 总高度或所有效果组合的性能。
