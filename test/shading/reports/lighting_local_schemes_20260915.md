# 最低环境光、人物与多光源方案样板

2026-09-15。仅独立光照样板；所有参数继续自动保存到嵌套项目 `user://settings.cfg`，不生成世界存档，不运行正式性能基准。

## 最低环境光

“环境光渐变”新增最低环境光强度（0–0.2，默认 0.015）和暗处补光颜色。方块、植被、测试人物的显示使用：

`环境光颜色 = 原天空环境光颜色 × (1 − 最低强度) + 暗处颜色 × 最低强度`

AO 和基础材质仍参与最终结果。这是可见度补光，完全密闭处也能看见；设置为 0 恢复原来的零光。它不修改体素光照数组、不重建网格、不改变阴影遮挡。当前水面仍沿用其专用吸收 / 反射 / 天空补光，不使用这套方块暗处下限。

## 局部照明方案

| 方案 | 体素照明 | 点光源 | 点光源阴影 |
|---|---|---|---|
| 仅自发光 | 不显示局部传播光 | 无 | 无 |
| 体素传播光 | 使用“体素主照明强度” | 无 | 无 |
| 点光源＋阴影（默认） | 可选原有弱补光 | 每个发光方块一盏 | 全部开启 |
| 点光源无阴影 | 可选原有弱补光 | 每个发光方块一盏 | 关闭 |
| 体素光＋限额点光源 | 使用“体素主照明强度” | 按相机距离选择，默认上限 8 | 已选灯中默认上限 4 |

切换方案保留世界、光源位置与传播结果，便于在同一布局比较；各方案仍有太阳 / 天空光等全局照明。“仅自发光”只关闭局部照明，不会关闭太阳。局部照明方案直接决定是否启用点光源，已移除重复的局部直射开关。点光源强度为 0 时同时停止其阴影。

体素主照明强度范围 0–3，默认 1；最终仍乘方块光颜色、补光亮度系数并应用方块光衰减曲线。当前传播是单色光等级场加统一颜色，不是彩色 GI；只修改显示强度，不改变传播距离。体素方案没有人物逐灯投影，并保留沿连通空间绕墙角传播的近似。

混合方案点光源上限 0–32、阴影灯上限 0–16，实际阴影灯不超过启用点光源数。每 0.2 秒按观察距离重新分配，不合并灯簇、不做遮挡可见性评分，也没有跨灯渐变；选择变化可能导致亮度 / 阴影跳变。无阴影点光源可能穿墙。混合照明可能叠加偏亮，可分别调低体素主照明强度和点光源强度。该方案用于评估，不是完成的大世界灯光分配器。

顶部显示总光源方块、启用的点光源、启用阴影的灯数量。这里显示脚本启用数，不代表引擎阴影图集实际分配槽位数。纯体素方案保留灯节点以快速切换，但能量归零、阴影关闭。

方块自身颜色和自发光倍率也已独立开放（默认暖黄 / 1.5，倍率 0–8），不再随点光源颜色修改。2026-09-18 修正：unshaded 材质直接使用“自身颜色 × 自发光倍率”输出，倍率为 0 时方块表面变黑；不删除灯块，也不关闭照亮周围的局部光。Bloom 继续独立控制。

## 批量放置

先调“批量光源数量”（1–32，默认 16），再点击“放置测试光源（按设置数量）”。布局固定在样板南侧 x=−25…−4、z=15…27、y=1，共 8 列 × 最多 4 行；点击“多光源观察”切到一致观察点。重新放置先清理上一批，不累积数量。

“清除测试光源”恢复这批位置的原始方块。若某位置已经被用户改成非光源方块，则保留用户编辑。这个按钮只管理它放置的测试批次，不删除室内灯或其他手动灯。设置数量本身不会立即修改世界。

## 简单人物

程序化头部、躯干、双臂、双腿，无外部模型资产。人物默认显示、启用摆臂与水平移动；可调整动画速度、移动幅度、尺寸倍率，也可以冻结动作。人物材质接入现有环境光、局部光、云影与平面反射裁剪。

按钮：“人物：岸边反射”“人物：涉水反射”“人物：多光源区域”。可在同一位置切换 SSR / 平面反射，观察动作与倒影、水位裁剪及灯光。涉水位置固定，水下部分在平面反射捕捉中剔除。

人物只有网格与关节变换，没有碰撞、物理、导航、玩家控制器或体素占位。它不会阻挡体素光传播，但可以投射实时几何阴影。尺寸 / 移动幅度过大可能与样板物体相交；停用人物动画可减少多光源对比中的变量。
