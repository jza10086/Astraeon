# 硬阴影诊断、彩色阴影过滤与日月外观

## 硬阴影

Godot 4.7 / Forward+ / D3D12，RTX 3060 Laptop GPU，1280×720。固定正午、4096 阴影贴图、0.06 深度偏移、2.0 法线偏移。首轮两视角未出现显著异常；扩展到四视角后，零 shadow_blur 在第三视角出现大面积错误变暗和边缘噪点，与用户报告相符。禁用云与彩色阴影仍出现；保持硬采样和四级级联，仅将 shadow_blur 改为 1，异常消失。单级投影也作了对照。共 16 张扩展对照截图保留于 tmp/shadow-diagnostics-expanded。

修复：方向光和样板局部灯在硬采样下使用中性倍率 1；软阴影倍率下限为 0.001，避免零值。硬/软采样仍由 RenderingServer 的质量模式区分，不通过倍率 0 模拟硬阴影。这是已验证的配置触发点和项目修复，不宣称已经定位 Godot 引擎内部数学根因。

[修复前](screenshots/shadows_celestial/hard-before.png) / [修复后](screenshots/shadows_celestial/hard-after.png)。树叶高频棋盘的投影混叠仍可能存在，不等同于此次整片地面错误自遮挡。

## 人工过滤对比

入口：shading_sample → 光照 → 彩色透明阴影。开启模块后选择“彩色阴影过滤方案”。

| 方案 | 每像素比较次数 | 说明 |
| --- | --- | --- |
| 最近邻 | 1 | 无过滤基准 |
| 原四点 | 4 | 原实现等权四角采样 |
| 双线性比较 | 4 | 对比较后的透射结果作双线性权重混合，默认；不插值深度 |
| 3×3 Tent | 9 | 三角权重核 |
| 5×5 Tent | 25 | 更宽的三角权重核 |
| 圆盘 8 点 | 8 | 固定黄金角圆盘分布 |
| 圆盘 16 点 | 16 | 更密的固定圆盘分布 |

比较次数不等于 GPU 耗时，每次还可能读取颜色纹理。未测性能。过滤半径只在可调核方案显示；分辨率、覆盖范围、偏移仍独立。建议固定时间和视点，先固定分辨率/范围，仅切换方案，再调半径。方案效果由用户人工评估，默认选择不是性能排名。

## 日月外观

入口：光照 → 日月外观 → 关闭 / 程序化圆盘 / 贴图圆盘。可调太阳/月亮角直径、各自颜色与显示亮度、边缘过渡和光晕。共用现有昼夜角度，地平线下淡出；显示参数不控制真实直射光强度。天空材质被平面反射环境复用；实体云通过场景深度遮挡天空。此轮未单独验收云遮挡和水面反射中的日月。

贴图为项目自制 SVG，占位艺术风格；源文件位于 game/shading/assets/celestial，可替换。当前月亮为固定满月图，不含月相或天文轨道。截图为方便观察临时使用 6 度直径，默认太阳 1 度、月亮 1.2 度。

[程序化太阳](screenshots/shadows_celestial/sun-procedural.png) / [贴图月亮](screenshots/shadows_celestial/moon-textured.png)。
